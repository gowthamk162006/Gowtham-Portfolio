# Gowtham: Portfolio

Static one-page portfolio (HTML, CSS, JavaScript). No build step.

## Files
- `index.html` content and structure
- `style.css` all styling (colours are CSS variables at the top)
- `script.js` mobile menu and active-link highlighting
- `assets/favicon.svg` site icon

## Run locally
Open `index.html` in a browser, or run `python -m http.server` in this folder.

## Deploy
**GitHub Pages:** push these files to a repo, then Settings > Pages > deploy from branch `main`, folder `/ (root)`.

**Vercel:** import the repo (or drag the folder into vercel.com/new). Framework preset: Other. No build command, output directory left blank.
